# Product Specification

---

## A. User Features

### Required Features (MVP)
1. Users can create and manage a car profile with basic details (make, model, year, mileage).  
2. Users can log maintenance tasks (oil changes, tire rotations, inspections).  
3. Users receive reminders for upcoming or overdue maintenance tasks.

### Optional Features
1. Users can upload photos or receipts for each maintenance record.  
2. Users can track multiple cars.  
3. Users can view analytics, such as cost per month or maintenance history charts.

---

## B. Screen Archetypes

1. **Home / Dashboard Screen**  
   - Displays upcoming reminders, recent maintenance logs, and quick access to car info.

2. **Car Profile Screen**  
   - Shows car details and allows editing or adding car information.

3. **Maintenance Log Screen**  
   - Shows a list of all maintenance tasks completed.

4. **Add/Edit Maintenance Screen**  
   - Users can add a new maintenance record or update an existing one.

5. **Settings Screen (Optional)**  
   - Manage notifications, account settings, and multi-car preferences.

---

## C. Navigation Flow

### Tab Navigation
- **Dashboard**
- **Car Profile**
- **Maintenance Log**
- **Settings** (optional)

### Flow Navigation (Screen-to-Screen)

**Dashboard Screen →**
- Car Profile Screen  
- Maintenance Log Screen  
- Add Maintenance Screen (via “Add” button)

**Car Profile Screen →**
- Edit Car Profile  
- Maintenance Log Screen  

**Maintenance Log Screen →**
- Add Maintenance Screen  
- Edit Maintenance Screen  
- Dashboard Screen  

**Add/Edit Maintenance Screen →**
- Back to Maintenance Log  
- Back to Dashboard  

**Settings Screen →**
- Back to Dashboard  
- Back to Car Profile
