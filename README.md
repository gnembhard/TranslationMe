# TranslationMe 

TranslationMe is an iOS translation application built with **SwiftUI** that allows users to translate words, phrases, and sentences between multiple languages. The app uses a translation API for real-time translations and **Firebase Firestore** to store and manage translation history.

The app features a modern card-based interface with language selection, clean input/output sections, and easy-to-use controls designed for a smooth user experience.

## Features

### Core Features
- Translate words, phrases, and sentences between languages
- Real-time translation using an external translation API
- View translation history directly within the app
- Store previous translations using Firebase Firestore
- Clear translation history when needed
- Simple and intuitive SwiftUI interface

### Additional Features
- Support for multiple languages:
  - English
  - Spanish
  - French
  - German
  - Italian
  - Portuguese
  - Chinese

- Modern UI design:
  - Card-style translation sections
  - Rounded action buttons
  - Shadows and accent colors
  - Improved layout and usability

## Technologies Used

- **SwiftUI** — iOS user interface development
- **Firebase Firestore** — Cloud database for storing translation history
- **Translation API** — Real-time language translation
- **Xcode** — Development environment
